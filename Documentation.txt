4. FILE & FOLDER REFERENCE
================================================================================

FILE: index.html
  Purpose  : HTML entry point. Mounts React app to <div id="root">.
  Key line : <script type="module" src="/src/main.jsx"></script>
  Favicon  : /Assets/LOGO.png

FILE: src/main.jsx
  Purpose  : Custom client-side SPA router.
  Logic    :
    - Reads window.location.pathname to determine which page to render.
    - Intercepts all <a> link clicks within the same origin.
    - Uses history.pushState to navigate without full page reloads.
    - Scrolls to top on page change (behavior: instant).
    - Smooth scrolls to #anchor links within the same page.
  Routes   :
    /            -> renders HomePage
    /index.html  -> renders HomePage
    /about       -> renders AboutPage
    (all others) -> renders NotFoundPage

FILE: src/pages/HomePage.jsx
  Purpose  : Main landing page with all sections.
  Exports  :
    - default: HomePage (full page component)
    - Header               (navigation header)
    - Footer               (site footer)
    - BookingFilter        (appointment booking bar widget)
    - STYLES               (complete CSS string)
    - WHATSAPP_LINK        (WhatsApp URL with pre-filled message)
    - SERVICE_AREAS        (list of service areas in Bangalore)
    - SPECIALIZATIONS      (doctor's clinical specialization cards)
    - CONDITIONS_WE_TREAT  (all treatable conditions grouped by category)
  Size     : ~148 KB

FILE: src/pages/AboutPage.jsx
  Purpose  : Doctor's Profile page (/about)
  Imports  : Header, Footer, STYLES, SERVICE_AREAS, SPECIALIZATIONS,
             BookingFilter, WHATSAPP_LINK from ./HomePage.jsx
  Key Data : SKILLS list, GALLERY_IMAGES list, ABOUT_STYLES (extra CSS)

FILE: src/pages/NotFoundPage.jsx
  Purpose  : Custom 404 page for unknown routes.
  Imports  : STYLES from ./HomePage.jsx
  Content  : Logo, large "404" text, "Page Not Found" message, Back to Home button.

FILE: api/contact.js
  Purpose  : Vercel serverless function - handles POST from contact form.
  Route    : POST /api/contact

FILE: vite.config.js
  Content  :
    import { defineConfig } from 'vite';
    import react from '@vitejs/plugin-react';
    export default defineConfig({ plugins: [react()] });

FILE: vercel.json
  Rewrites:
    /api/(*) -> /api/$1   (passes API requests to serverless functions)
    /(.*)    -> /index.html  (all other routes -> SPA HTML)

FILE: package.json
  Name    : movewell-preview
  Scripts :
    npm run dev      -> start Vite dev server on localhost:5173
    npm run build    -> build production bundle to /dist
    npm run preview  -> preview production build locally
  Dependencies:
    react, react-dom          - UI framework
    vite, @vitejs/plugin-react - build tooling
    nodemailer                 - email in API

8. ROUTING & NAVIGATION
================================================================================

Router File: src/main.jsx

How It Works:
  - No React Router or routing library used.
  - Uses browser History API (history.pushState) for SPA navigation.
  - Global click listener intercepts same-origin <a> tag clicks.
  - On path change: updates React state -> correct page component renders.
  - On logo click: scrolls to top if on /, navigates to / if on another page.
  - On hash links (/#contact): smooth scrolls to element on page.

Route Table:
  /           -> HomePage
  /index.html -> HomePage
  /about      -> AboutPage
  (any other) -> NotFoundPage

Logo Navigation (from anywhere):
  - On /about or 404: navigates to /
  - Already on /: smoothly scrolls to the very top

Internal Links:
  - "/#contact" from About page -> navigates to / and scrolls to contact form
  - "#services", "#pricing" -> smooth scroll within same page

17. KNOWN ISSUES & NOTES
================================================================================

1. ESM CDN React Imports
   React is imported from esm.sh CDN (not standard npm import).
   Vite generates harmless warnings about unused default imports.
   These do not affect runtime functionality.
   Future: Switch to standard npm React imports for cleaner builds.

2. Assets Must Be in public/Assets/
   The duplicate root Assets/ folder was removed.
   All new images MUST go into public/Assets/ (or subdirectories).
   Reference them in JSX as: ./Assets/filename.jpg

3. WhatsApp Business Name
   The number shows as a raw phone number to users who haven't saved the contact.
   Fix: Install WhatsApp Business App and set up the clinic business profile with
   name, logo, hours, website, and description.

4. Contact Form SMTP Not Set
   If SMTP_PASSWORD is not configured in Vercel, form returns 200 but sends no email.
   Always verify after deployment by submitting a test form and checking inbox.

5. Unsplash Images (External CDN)
   Three cards use Unsplash URLs (Neurological Rehab, Sports Injury, Hybrid Physio).
   These depend on Unsplash CDN availability.
   Recommendation: Download and host in public/Assets/ for full reliability.

6. Blog Articles - No Links
   The 3 blog cards are visual-only and do not link to actual articles.
   Future: Create /blog route with individual article pages.

7. Instagram Link
   Instagram icon in footer links to "#" (placeholder).
   Update with real Instagram URL when account is available.
